# Cinnamon's Buns -- Bakery Website

Cinnamon's Buns is a fully functional bakery website featuring a modern
interface, product gallery, online shop with cart functionality, and a
contact page for inquiries and special orders.\
The website showcases baked goods, best-selling items, product details,
and a seamless shopping experience designed for small businesses or
local bakeries.

# Features

# Homepage (index.html)
-   Clean hero section introducing the bakery
-   Displays featured and best-selling bakery items
-   Navigation to all major pages
-   Search bar for quickly finding items
-   Links to Shop, Gallery, About, and Contact pages
-   Place Order Button
-   Quick Contact information

# About Page (about.html)
-   Story of the bakery
-   Background, mission, and history
-   High-quality images related to the bakery brand
-   Place Order Button
-   Trading Hours
-   Location information

# Gallery Page (gallery.html)
-   Visual showcase of bakery products
-   Includes items not yet available in the Shop
-   Used to highlight creativity and variety of baked goods
-   Functions as the website's portfolio
-   Photos of Treats
-   Place Order Button (also at the end of each category)
-   Shop Now Button

# Shop Page (shop.html)
-   Complete product listing
-   Each product includes image, name, price, and Add-to-Cart button
-   Functional shopping cart with item count, removal, clear-all, and
    total calculation
-   Cart persists using LocalStorage

# Contact Page (contact.html)
-   Email form for inquiries or special orders
-   Contact information
-   Business Hours
-   Phone Number
-   Email Address
-   Map Location

# Order Page (order.html)
-   Menu with images organized by categories:
    - Signature Swirls (cinnamon rolls and chocolate chip cookie)
    - Sweet Classics (cookies and cupcakes)
    - Mini Treats & Gift Boxes (donuts, cookies, other small treats)
    - Events and Special Treats (cakes)
-   Place Order Button (also at the end of each category)

# Search Engine
-   Searches through product names
-   Filters shop items dynamically
